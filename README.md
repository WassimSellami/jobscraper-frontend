# LinkedIn Job Scraper Dashboard

An Angular dashboard for scraping and browsing LinkedIn job listings.

**Live:** [jobscraper-frontend-5fxf.onrender.com](https://jobscraper-frontend-5fxf.onrender.com/)

**Backend:** [github.com/WassimSellami/JobScraper](https://github.com/WassimSellami/JobScraper)

## Features

- Filter by search terms, job level, location, distance, and age
- AG Grid table with infinite scroll
- Dark mode toggle
- CSV export
- KPI row showing total jobs found

## Setup

```bash
npm install
npm start
```

The app runs at `http://localhost:4200` and expects the backend at `http://localhost:8000`.
